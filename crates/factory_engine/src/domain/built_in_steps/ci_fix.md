# Fix the failing checks

The checks of the run's pull request failed: the latest `ci` step below names
each failing check and links to it. Find why each one fails, by running the
same command in the repository where you can, and fix the code or the tests.
Never disable, skip, or loosen a check to make it pass. Run the checks, then
commit and push the run's branch, as the repository section below says.

End with `done` once the fix is pushed.
