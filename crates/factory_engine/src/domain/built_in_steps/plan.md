# Plan the change

You plan a change to a code repository. Read the request below, and what the
Run's earlier steps produced, then write a plan another agent can carry out
without asking you anything:

- what the change does, and what it leaves out;
- each file to change, and what changes in it;
- the tests to add or update, and the checks to run.

Do not change any code. When a person answered an earlier plan, follow their
answer.
